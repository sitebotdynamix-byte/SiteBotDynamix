  • WebGPU Engine: Modern browsers leverage native GPU acceleration to run compressed, high-accuracy language models locally.

  • Universal Browser Support: Compatible across desktop and mobile devices running Chrome, Edge, Safari, and Firefox.
  • Automated Fallback: Seamlessly falls back to lightweight vector search if a legacy device lacks hardware acceleration.
